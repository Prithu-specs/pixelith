# App review instructions

1. Install and launch the Pixelith desktop build on a Mac, Windows PC, or Linux
   computer connected to the same private Wi-Fi as the review phone.
2. Enable **Allow mobile companion**. The desktop displays a temporary six-digit
   code and advertises `_pixelith._tcp.local`.
3. Launch the mobile companion, select the discovered desktop, and enter the
   code. No account or permanent password is required.
4. Choose one photo with the system photo picker, select 1080p or 4K, review the
   estimate, and start the job.
5. The media travels only over the local network to the review desktop. It is
   never uploaded to PGA Tech Solutions or used for AI training.
